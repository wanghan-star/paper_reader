# 保留公式、完整段落与图片

问题：PDF 文本层只提供按位置排列的字符，直接按空格拼接会丢失公式结构。短行的启发式标题识别还会把图内标签拆成正文；图片未进入中英对照阅读。

采用逐页视觉结构识别：本地渲染整页交给 Codex，在一次任务中返回正文段落、标题、独立公式、图表、表格及对应中英文本和归一化区域。原始图像在浏览器本地从 PDF 渲染，不由模型重新绘制。

- 上传后暂时显示保留的完整原页，隐藏未经确认的乱码文本。开始翻译时识别版面并翻译，每页完成后显示中英对照。
- 印刷换行拼成完整自然段；图内坐标、标签和表格内容保留在原图中，不作为独立译文行。图注按中英两行跟随原图。
- 独立公式不重复翻译，采用标准数学块排版，保留上下标、分式与公式编号。每条公式可展开对应原图；无法辨认时直接显示原图，不猜测。
- 图片和表格直接在阅读页显示，支持放大、整图解释、局部框选；问题保持原始页码与正文上下文。
- 结构识别失败时完整原页继续保留，可重试或切换模型。空白页可返回空结构。原文核对入口持续保留。
- 缺少中文译文的有效文字块沿用已有小批次翻译与补译流程；取消、任务队列、只读临时会话及模型切换保持兼容。
- 每个文档只缓存最近四页的渲染结果，图表复用页面光栅；公式原图及完整原页仅展开时加载。

数据说明：PDF 原件仍不上传，但现在每个需翻译的页面会发送整页渲染图像和辅助文本到 Codex。需要在 README 和使用说明中明确此行为与账户额度使用。

验证使用自制包含上下标、独立带编号分式、矢量曲线图和嵌入图片的 PDF；检查真实 Codex 结构识别、公式排版、图像保留、局部框选、移动端宽度。未拿到用户截图所对应的完整 PDF，不能声称逐页核验了该论文。
